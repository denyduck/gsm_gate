Import (obnova)

Pravidelné zálohování

Pro automatické pravidelné zálohy použij management příkaz přímo v kontejneru (lze naplánovat přes systemd timer stejně jako watchdog - viz scripts/): 

docker compose exec -T web python manage.py export_backup --kind data --output-dir /usr/src/app/backups

Adresář backups/ je uvnitř bind-mountovaného django_app/, takže soubory najdeš přímo na hostu - odtud si je synchronizuj (rsync/rclone/cloud sync) tam, kam potřebuješ.
